# Saksham Lamsal — Developer World

An interactive, recruiter-friendly portfolio that combines a professional software profile with an original creature-adventure world.

## Stack

- React 19 + TypeScript + Vite
- Three.js, React Three Fiber and Drei
- Framer Motion
- Tailwind CSS
- Lucide React

## Features

- Procedural low-poly 3D environment with terrain, water, mountains, trees, buildings, an original developer avatar and original companion creatures
- Poké Ball-inspired loader, floating navigation and project interactions
- Data-driven project profiles with architecture, features, challenges and learnings
- Project discovery stored locally in the browser
- Day/night mode, automatic/manual 3D quality levels and reduced-motion control
- Responsive layouts and device-aware rendering
- WebGL fallback; all professional content remains available without 3D
- Keyboard navigation, semantic structure, focus states and reduced-motion support
- Lazy-loaded 3D bundle and split vendor chunks

Note: The visual design is Pokémon-inspired and uses original procedural geometry. This project is not affiliated with Nintendo, The Pokémon Company, or Game Freak.
